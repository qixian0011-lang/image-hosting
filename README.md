# image-hosting

图片图床仓库。所有图片放在 `images/` 目录下。

## 直链规则（raw URL）

    https://raw.githubusercontent.com/qixian0011-lang/image-hosting/main/images/<文件名>

示例：

    https://raw.githubusercontent.com/qixian0011-lang/image-hosting/main/images/size-chart-square.png

## 使用注意

- 文件名建议只用英文、数字、连字符（-），不要用中文和空格，否则 URL 需要转码。
- 仓库为 Public，链接可直接外链引用（如 Listing、Embed 等）。
- 单文件不要超过 100 MB（GitHub 硬限制）。
